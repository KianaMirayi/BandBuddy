BandBuddy `1.3.0` 新增视频练习，并简化反复练习片段时的播放操作。

## 新功能

- 支持导入 `MP4 / M4V / MOV / MKV / WebM / AVI`。先在本机提取视频音频，再生成六条分轨；原始视频保留在曲库中。
- 视频歌曲在练习室显示视频画面和六轨混音控制，替代波形。画面跟随音轨的播放、暂停、跳转、A–B 循环与 `0.20×–4.00×` 变速；原视频音轨静音。
- 支持全屏视频播放。全屏内保留播放、进度、变速、A–B 循环和跳回控制，按 `Esc` 退出全屏不会清除循环。
- A–B 合并为一个按钮：第一次设 A，第二次设 B 并立即从 A 开始循环，第三次取消。按钮图标、标记和动画显示当前状态，快捷键 `L` 使用同样的操作顺序。
- 新增“跳回并播放”按钮和 `Home` 快捷键：循环启用时跳回 A 点，否则跳回歌曲开头；即使原本暂停也会直接开始播放，不重复预备拍。

## 兼容性与修复

- 已有音频曲库、六轨波形和练习设置保持兼容，数据库自动迁移。
- 修复 B 点位于歌曲末尾时循环可能停止，以及自然播放结束后实际音频位置未回到开头的问题。
- 连续快速跳回时，过期的播放请求不会再暂停最新一次播放。
- 视频必须包含可读取的音轨。常见 H.264、VP8/VP9 视频优先重封装，其他编码转换为本地播放副本；长视频或高分辨率视频会增加准备时间与磁盘占用。
- 本版仍导出音频分轨或音频混音，不生成带分轨混音的视频文件。

## 本地 Windows 构建

- `BandBuddy-1.3.0-x64.exe`：Windows 10/11 x64 安装版。
- `BandBuddy-1.3.0-x64-portable.exe`：Windows 10/11 x64 便携版。

未配置 Authenticode 证书的本地构建会显示“未知发布者”。
