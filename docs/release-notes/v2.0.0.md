# BandBuddy 2.0.0

BandBuddy 2.0 把原来的六轨分离扩展为两阶段九轨链路，并加入面向吉他手的 Acoustic / Lead / Rhythm 即时切换。

## 新功能

- 每首新歌先用 HTDemucs 生成 Vocal、Drums、Bass、Guitar、Piano、Other，六轨完成后立即开放练习室；Acoustic、Lead、Rhythm 在第二个持久化任务中继续生成。
- 练习室新增“吉他分轨”按钮。关闭时保留熟悉的六轨视图；开启时自动隐藏并关闭原 Guitar，显示三条吉他细分轨。
- 第二阶段运行时“吉他分轨”按钮置灰并提供等待提示；当前练习歌曲完成后按钮自动恢复，旁边显示完成浮窗，新增轨按当前播放位置接入。
- 模式切换使用短交叉淡化；每条轨的 Mute、Solo、增益和输出通道设置互不覆盖。
- 设置新增“高音质分轨”：默认使用九轨 320 kbps MP3 节省空间，开启后新任务统一保存为九轨 24-bit FLAC。
- 分轨导出默认跟随当前模式，也可显式包含隐藏的吉他备选轨；混音导出严格排除隐藏轨。

## 可靠性与迁移

- 音质设置在创建任务时快照，修改设置不会改变正在运行或已经排队的任务。
- 新歌六轨编码、探测和波形完成后原子激活，并在同一事务中排入吉他细分；重新分轨则等两个阶段都成功后才替换旧版本。
- 每阶段应用一致上限的全局峰值余量，避免 24-bit FLAC 硬削波，同时保持阶段内各轨相对电平不变。
- 旧六轨歌曲首次打开吉他分轨时会提示重新处理；没有原始音频的历史歌曲仍可播放和导出，但不能生成新的吉他细分轨。
- 旧设置缺少音质字段时默认关闭高音质；旧练习状态自动补齐三条吉他轨状态，并保持吉他分轨关闭。
- 已移除“导入已有分轨”的新建入口和 IPC；历史上已导入的歌曲数据不会删除。

## 本地运行环境

- 固定 Python 3.12、PyTorch/Torchaudio 2.11.0 和 Demucs 4.1.0。
- 四份固定权重从公开 ModelScope 仓库的 `v2.0.0` 分支一次性安装，支持断点续传，并验证固定大小和完整 SHA-256。
- 加速设备不可用或显存不足时，在 CPU 上用相同质量参数重跑，不降低 TTA、overlap 或分块质量。
- 2.0 首发包支持 Windows 10/11 x64 和 macOS Apple Silicon。
