# BandBuddy 2.0.1 — macOS

本次发布适用于 **Apple Silicon Mac（arm64，M 系列芯片）**。安装包中的应用已使用 Developer ID 签名、通过 Apple 公证并附加公证凭据，Gatekeeper 验证通过。

## 更新内容

- 包含吉他分轨功能：木吉他、主音吉他、节奏吉他，支持 fast / balanced / high 质量策略。
- 修复模型下载返回 404：补齐 ModelScope v2.0.1 模型资源，并同步共享模型的 SHA-256 校验值。
- 已完成全部六个模型的匿名下载及完整性校验。

## 下载与安装

- 推荐下载 `BandBuddy-2.0.1-macos-arm64.dmg`，打开后将应用拖入 Applications。
- ZIP 提供同一已公证应用；`SHA256SUMS-macos-arm64.txt` 用于校验下载文件。
- `VERIFICATION.md` 提供签名、公证和安装包验证记录。
- 本次仅提供 macOS arm64 安装包，不包含 Intel Mac 或 Windows 2.0.1 构建。

## 验证与已知问题

应用测试 166 项、模型下载测试 10 项、吉他分轨管线测试 6 项通过；类型检查、生产构建及原生音频自检通过。本轮未重新进行整曲推理及主观音质评估。

启动检查仍发现原生音频设备枚举的 `invalid UTF-8 byte` 错误，可能影响录音及设备选择，该问题尚未修复。
