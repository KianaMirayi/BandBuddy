BandBuddy `1.2.0` 围绕“换调后仍然能完整练习和录音”补齐实时升降调、歌曲调识别与带调性导出，同时修复音频设备失效和排练恢复播放时的多项可靠性问题。

## 新功能

- 使用 Signalsmith Stretch 为 Vocal、Bass、Guitar、Piano、Other 实时升降调，范围为 `-12–+12` 半音、步进 1 个半音；Drums 保持原音并自动补偿处理延迟。
- 升降调会随歌曲保存，并贯穿单曲练习、连续排练、录音 Take 和导出；练习室会同时显示原歌曲调与换调后的歌曲调。
- 在本机分析非鼓分轨，识别歌曲主音与大小调。界面显示置信度、前三候选和可能转调的片段，支持手动纠正；重新分析不会覆盖手动结果。
- 分轨和当前混音导出会保留当前升降调：非鼓轨使用 Signalsmith 处理，鼓轨保持原音；录音 Take 只有在录制速度和调性都与当前练习一致时才参与预听、排练和导出。
- 曲库歌曲菜单新增“编辑歌曲信息”，无需先进入练习室即可修改标题、艺术家、BPM、歌曲调和拍号。
- 设置新增切换后立即生效的 Debug 模式和“打开日志位置”入口，可记录 renderer、preload、IPC 与进程异常；代理凭据、令牌和密码继续脱敏。

## 可靠性与修复

- 启动时核对播放与录音设备。已保存设备断开、方向不再可用、通道或采样率失效时，会回到当前系统默认值，并恢复该设备组合保存过的对齐偏移。
- 播放器加载歌曲时，若记忆的输出设备已经消失，会回退系统默认输出；默认输出也不可用时仍会明确报错。
- 排练播放会串行处理音频配置并等待正在进行的歌曲准备，修复恢复播放时界面显示已播放但声音没有重新启动的问题。
- 排练录音叠加层会跟随实时变调延迟对齐；排练时间线版本现在把每首歌的升降调计入指纹。
- 每次打开导入窗口都会清空上一次选择的文件和元数据，避免连续导入时残留标题或艺术家。
- 原生音频宿主加入 `+12 / -12` 半音离线处理自测，并验证输出时长与基本频率变化。

Windows 社区构建在没有 Authenticode 证书时会显示“未知发布者”；macOS 构建目前未使用 Developer ID 签名或公证。实时升降调失败时播放器会保持原调并提示；录音时仍推荐使用声卡或调音台的硬件直通监听。
