Date: 2026-09-12

## Model download fix

The application requested ModelScope `Zzzzzzorz/BandBuddy-Models` revision `v2.0.1`, but the repository only contained `v2.0.0`. All six requested URLs returned HTTP 404. The older bundle does not contain the shared acoustic/electric checkpoint or the three fast-mode checkpoints, so changing the revision to v2.0.0 would not fix the current model architecture.

Published the missing weights, configuration snapshots, manifest, build audit and provenance to the existing repository, then created the v2.0.1 tag at commit `fff674650e6dc94377ef16df8af75421c4ce142a`. The v2.0.0 tag is unchanged.

Seven original source checkpoints were downloaded from the existing v2.0.0 release and the pinned upstream Hugging Face revision `46ca65d52c07635a4992fadb9c6b1644eb51fe7f`. All original sizes and SHA-256 values matched the build script. The shared checkpoint was generated with the repository build script, loaded strictly into the model, and every tensor was compared to the combined source tensors. A second serialization produced the same checksum.

The rebuilt shared checkpoint is 102,410,137 bytes, SHA-256 `183607bffbebdb43dcb3fd583b7cbe3c77fb55aea886cbd1e3aa316d9148698c`. The downloader, inference spec and pinned manifest test now use this published binary's digest. The previous unpublished digest could not be reproduced by this build; the reason for the serialization difference was not established. The model tensor contents were independently verified, and hash verification remains mandatory.

## Validation

- Actual application downloader completed a fresh, anonymous download of all six models from v2.0.1 with retries disabled. Every byte count and SHA-256 passed, and the completion marker was written only after verification.
- Packaged downloader verified the freshly downloaded bundle; packaged inference specs match the downloader's hashes.
- Python model downloader tests: 10 passed. Guitar separation pipeline tests: 6 passed.
- Application tests: 166 passed across 38 files after making the video fixture use the macOS tool bundle's libx264 encoder. Windows retains libopenh264.
- Type checks, production build and native audio host self-tests passed.
- This run did not perform full-song neural inference or a subjective audio quality assessment.
