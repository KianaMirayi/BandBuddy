The current signed application was uploaded using Xcode's existing account session with Developer ID distribution. No new credentials or certificates were created. Apple issued a ticket that was stapled to the exact submitted application. Gatekeeper accepted it with source `Notarized Developer ID`.

The final DMG and ZIP were built from this already-notarized application using electron-builder's `--prepackaged` option, without re-signing the app. The fixed release verification hook ran with `mac.notarize=true`.

Validation:
- All 21 Mach-O files: valid Developer ID signatures from the expected publisher, Hardened Runtime and secure timestamps.
- Complete app signature and resource seal: valid.
- Both DMG-mounted and ZIP-extracted applications: stapled ticket valid; Gatekeeper accepted as Notarized Developer ID.
- DMG container signature and image checksum: valid.
- Isolated startup of the ZIP-extracted app outside the source tree: passed, FFmpeg ready.
- app.asar and 16 Python worker files: byte-identical to the signed build before notarization.

Artifacts: `release-macos/notarized-2.0.2/BandBuddy-2.0.2-macos-arm64.dmg` and `.zip`. SHA-256 checksums and `SIGNATURE-REPORT.json` are in the same directory. These supersede the earlier signed-only testing builds for distribution.
